# agentnaming.ai

Source for https://agentnaming.ai (this repository: https://github.com/AgentNaming/agentnaming.ai),
the site of Personal Agent Naming (PAN), an
open standard for naming personal agents, sponsored by AgentMesh.

The specification is `SPEC-NAMING.md`, published at https://agentnaming.ai/spec.html, with
its source in https://github.com/AgentNaming/personal-agent-naming. This repository renders it
as `spec.html` and holds the pages that explain it. See `CLAUDE.md` for how to
change and publish the site.
